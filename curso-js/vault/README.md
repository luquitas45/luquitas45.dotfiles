# Curso JavaScript - Jon Mircha

Vault de aprendizaje práctico del curso de JavaScript de Jon Mircha.

## Estructura

- `01-fundamentos/` - Variables, tipos, funciones, arrays, objetos, operadores, condicionales, loops, clases, prototipos
- `02-modulos-asincronia/` - Módulos ES6, temporizadores, Event Loop, callbacks, promesas, async/await
- `03-nuevos-tipos-this/` - Symbols, Sets, Maps, WeakSets, WeakMaps, Iterables, Generators, Proxies, `this`
- `04-dom-bom/` - DOM, eventos, BOM, ejercicios del DOM
- `05-ajax-fetch/` - AJAX, Fetch, CRUD con AJAX/Fetch/Axios
- `proyectos/` - Proyectos integradores por bloque
- `templates/` - Plantillas para notas

## Cómo usar este vault

1. Cada video tiene su nota atómica con apuntes y ejercicios
2. Después de cada ejercicio/proyecto, completar el cuestionario que genera Pi
3. Las notas se conectan con `[[links]]` entre conceptos relacionados
4. El [[canvas-curso]] muestra el progreso visual del curso
